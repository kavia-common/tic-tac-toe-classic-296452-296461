# Tic Tac Toe Frontend (React)

A simple 2-player Tic Tac Toe game (same device).

## Features
- 3x3 grid
- X starts; turns alternate
- Winner detection (rows, columns, diagonals)
- Draw detection
- Reset game button

## Run locally
```bash
npm install
npm start
```

The app is configured to run on port `3000` (see `.env`).
